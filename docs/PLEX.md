# Plex Setup

Configure one Plex server under Settings → Plex.

Medialogue uses Plex read-only as secondary evidence. It does not trigger Plex scans and it does not edit Plex metadata.

Verification states include:

- Plex Verified
- Plex Pending
- Plex Conflict
- Plex Unavailable

An exact Plex path match is strong verification evidence. Explicit Plex disagreement creates an identity conflict; Plex being offline is only a service-health issue and does not detach otherwise valid local media.
