Add a storage root

Adding a root does not scan it. You initialize the first scan explicitly from the library page.

Name
Shown in Medialogue only. Has no effect on the filesystem.
Container path
The path as Medialogue sees it. Inside Docker this is the container-side mount, not the host path. Example: /media/films
Media type
Which library titles discovered under this root belong to.
Access
Read-only detects and reports but can never delete. Read/write additionally permits deletion, and only after an explicit preview and confirmation.
Removing a storage root never touches the files on it. Only Medialogue’s index of that root is cleared.

Administrator security

Medialogue uses a single local administrator account and secure session cookies. There is no self-service recovery — a lost password is reset from the server.

Enough to rebuild this installation on a new host. Your media is not included — the bundle describes your library, it does not copy it.
